> **U1 背景與已知事實:**
> - U1 = 使用者在手機打開「USB 網路共享(USB tethering)」,手機成為 DHCP/閘道,PC 透過 USB 取得一個區網 IP(常見 `192.168.42.x` 網段)。
> - 架構複用現有 TCP:PC 仍為 server(`0.0.0.0:58482`,已綁所有介面)、手機為 client。串流/握手/播放全部沿用現有 core 與協定,**不重造**。
> - **最大未知數(PoC 要回答的核心問題):zeroconf(PC 端)/ NsdManager(手機端)的自動探索,能否跨過 USB tethering 的 RNDIS 介面?** 如果不能,U1 就需要不同的連線方式(例如手機直接連 PC 在 tethering 網段上的 IP),這要靠實機測出來,不能假設。
>
> **第一階段:PoC(只調查與回報,先不做完整整合)**

> 4. 回報 U1 的建議實作方式、要新增/修改哪些檔案、以及風險。**回報後停下,等我回覆 ok 再進第二階段。**
